## 0. 结论摘要

- **战斗两段式**：开战前用 100 体力布阵；进入实时战斗后，每秒恢复 2 体力（上限 100），继续拖动卡牌补位或换阵。
- **持久单位与原位索敌**：部署后的卡为持久单位，有生命和攻击间隔，原位自动攻击；被击破后阵位空出。索敌优先攻击同路正对面敌方第一排，否则按敌方存活排从前往后、同排从上到下索敌；所有单位均可攻击任意存活排，不再有射程限制。
- **战场与人物位**：双方各 3 路 × 3 排（共 9 格阵位），双方阵型外侧各有一个不入 9 格的人物位（玩家在左、敌方在右），提供全阵光环，不占阵位、不受击、不计入空场判定。
- **三大阵营风格（取代原球类命名）**：
  - **【疾锋突击团】**（原乒乓球）：近战高频 · 极速补阵。12 张牌库总费 68，9 格最低铺满 41 费，留出大量体力高频补位与亡语铺场。
  - **【灵羽游击队】**（原羽毛球）：中距控场 · 阵型联动。12 张牌库总费 122，9 格最低铺满 74 费，以迟缓、再生与资源循环维持阵型。
  - **【重炮壁垒军】**（原网球）：远程重装 · 蓄力轰炸。12 张牌库总费 184，9 格最低铺满需 117 费，开局需要取舍；高血量前排保护重炮与蓄力爆发。
- **跨对局挑战与胜负**：挑战次数为跨对局探索资源，单场一次机会（战斗界面不显示）；战斗无阵心与主基地血条，任一方场上单位数为 0 持续 3 秒即分胜负，90 秒进入突然死亡。

## 2. 核心循环

1. **布阵阶段**：战场显示双方各 9 个阵位；玩家初始体力 100，手持 5 张牌并启用抽牌循环。拖动卡牌至空阵位部署。敌方开场阵型可见，玩家可针对性排兵布阵，并可自由拖动已上阵单位调整位置。点击“开始战斗”进入实时阶段（原型可设 20 秒可选倒计时）。
2. **实时战斗**：单位原位按攻击间隔自动攻击；体力每秒 +2。玩家拖牌至空位补位，或拖至已有单位上触发【换阵】。敌方按关卡 AI 规则持续补位。
3. **胜负结算**：敌方场上单位数为 0 持续 3 秒获胜；我方场上单位数为 0 持续 3 秒战败。90 秒未分胜负进入突然死亡（全场单位每 2 秒受 2 点真实伤害，双方体力恢复 +50%）。

## 3. 战场、阵位与索敌规则

```text
 人物        我方                     阵线                    敌方        人物
       后排   中排   前排                                 前排   中排   后排
[你]   [ ]    [ ]    [ ]               ┃               [ ]    [ ]    [ ]   [对手]
       [ ]    [ ]    [ ]               ┃               [ ]    [ ]    [ ]
       [ ]    [ ]    [ ]               ┃               [ ]    [ ]    [ ]
```

- **路与排**：上、中、下 3 路；我方前排与敌方前排靠近中央阵线。
- **原位不动与存活排索敌**：
  - 战斗中单位不发生位移，始终留在原阵位。
  - 所有单位均可攻击敌方**任意存活排**，没有射程限制；空排跳过。
  - **目标选择优先级**：
    1. 若同路有【嘲讽】单位，优先攻击该【嘲讽】单位（嘲讽不跨路生效）。
    2. 否则，优先攻击同路敌方第 1 条存活排上的单位。
    3. 若同路第 1 条存活排为空（或本路已无存活敌人），则跨路攻击敌方**第 1 条存活排**上的敌人；同排按上路→中路→下路顺序。
- **视觉可读性规范**：
  - 跨路攻击需绘制明显的弧形弹道轨迹；
  - 选中/悬停任意单位时，高亮显示其当前索敌连线及光环覆盖格；
  - 突然死亡扣血与普通受击跳字采用不同颜色与图标区分。

## 4. 体力、手牌与通用关键词

| 项目 | 规则 |
| --- | --- |
| 体力上限与恢复 | 初始 100，上限 100，战斗中每秒 +2；跨战斗不保留 |
| 手牌与牌库 | 手牌上限 5 张，打出 1 张抽 1 张；牌库抽空后洗入弃牌堆；单局携带 6–12 张构筑牌库 |
| 部署与换阵 | 拖至空位直接部署；拖至已有单位上支付新卡费用替换旧单位（默认不返还体力，具备【换阵】词条的卡牌除外） |
| 叠加软上限 | 同路同一单位最多同时受 2 层同类【光环】加成；场上最多同时存在 2 个纯产费【资源】单位生效 |
| 调参开关（候选，默认保持原值） | `opening_stamina` 布阵体力（默认 100）、`card_cost_multiplier` 全卡费倍率（默认 ×1.0）、`battle_cost_multiplier` 战斗中补位加价（默认 ×1.0）、`battle_reinforce_cooldown` 补位冷却（默认 0 秒）；档位实验见 `docs/BALANCE_BASELINE_V0_1.md` |

### 标准关键词词典（适用于全部 300 张卡）

- **【嘲讽】**：同路敌方单位必须优先攻击此单位。
- **【迟缓】**：命中后使目标攻击间隔 +50%，持续 3 秒（同类效果刷新时间不叠加倍率）。
- **【光环】**：持续强化同路相邻排友军的属性（攻击、攻速或减伤）。
- **【蓄力】**：每间隔数次攻击或固定秒数，下一次攻击造成高额倍率伤害。
- **【溅射】**：攻击主目标时，对同排或相邻路的敌人造成额外波及伤害。
- **【穿透】**：无视【嘲讽】，且优先锁定最靠后的存活排单位。
- **【亡语】**：单位生命归 0 退场时立即触发的结算效果（伤害、产费或留存残影）。
- **【换阵】**：将该卡直接拖放替换已有友军时，触发额外的强力入场效果或费用返还。

### 8.3 实现口径

- 跨路索敌不按距离偏置：同路正对面第一排无人时，先按存活排从前往后，同排固定上路→中路→下路。

- 穿透的“优先最后排”指全场最靠后的存活排。
- 亡语、穿透、蓄力由卡定义决定：双方使用同一张卡时都会获得该关键词，不限于关卡敌方实例。
- 原支线关（已移除）的“体力恢复压制”已改为卡面属性 `suppress_regen`，不再按 `level_id + card_id` 绑定；预留 BOSS 三阶段复用同一属性。
