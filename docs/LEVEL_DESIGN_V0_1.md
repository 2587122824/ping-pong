# 关卡设计 V0.1

> 状态：候选设计，五个样本已接入玩法原型用于验证；关卡数值和外部流程规则仍未定案，未作为正式产品决定写入 `DECISION_LOG.md`。
> 关联：`docs/CARD_BATTLE_RULES_V0_1.md`（D-023 体力费用、D-024 三套主题牌组）。

## 1. 目的与范围

先用最少的关卡样本跑通全部关卡系统，再从样本中提炼固定模板。共 5 个样本，覆盖纯教学、普通、精英、BOSS、支线五类关卡：

| 样本 | 关卡 | 类型 | 主要验证 |
| --- | --- | --- | --- |
| 1 | 发球机·初号 | 主线（教学） | 新手引导、基础出牌逻辑、体力与弃手抽 5 |
| 2 | 裁判机器人 | BOSS | 蓄力机制、章节结算、强化（MP）解锁位 |
| 3 | 陪练机器人 | 普通主线 | 常规节奏、战前提示、首次通关奖励、战前切换牌组 |
| 4 | 破防型选手 | 精英 | 破防机制、低容错数值、装备/卡牌奖励 |
| 5 | 节奏控制器 | 支线 | 压制资源机制、可重复挑战、支线奖励 |

本版不包含：关卡地图与流程编排、关卡内事件与分支对话、多敌人同场、关卡存档、难度选择。

## 2. 设计前提

以下数值来自已确认规则，是整套关卡设计的地基：

- 玩家生命 30，跨战斗保留；体力上限 100，每场战斗从满值开始，每回合恢复 20。
- 出牌费用：主攻 15、副攻 10、牵制 15、防御 10、资源 5、战术 5。
- 伤害：主攻 8、副攻 6、牵制 5；战术增幅后主攻 11；防御格挡 7；牵制使敌方本回合攻击减半。
- 牌组 6 张，每回合弃整手并抽 5 张，因此玩家每回合几乎能看到全部手牌。

由这些规则推出的四条关卡设计约束：

1. **开局是爆发窗口。** 前两回合每回合可花 45 点体力，打出约 22 点伤害，两回合合计约 44 点。血量低于 50 的敌人会在开局被直接推平，不能作为正常关卡。
2. **20 点体力只能选一个答案。** 每回合要么输出、要么格挡、要么牵制，三者在同一份预算里互斥。敌人的意图必须让这三个答案各自有存在的理由。
3. **30 点玩家生命承受不了堆伤害。** 约等于 3 次未格挡的普通攻击。敌人强度不能靠抬高单次伤害，只能靠血量与节奏错位。
4. **生命跨战斗保留，关卡链必须有恢复。** 否则第 3 场开始就是硬性失败，与玩家操作无关。

## 3. 通用关卡模板

所有关卡按同一组字段配置，新增关卡只填参数，不改结构：

| 字段 | 说明 | 取值示例 |
| --- | --- | --- |
| 关卡 ID | 章节-类型-序号 | `CH0-B01` |
| 名称 | 显示名 | 裁判机器人 |
| 类型 | 主线 / 支线 / 精英 / BOSS | BOSS |
| 敌人生命 | 见第 4 节数值基准 | 75 |
| 基础攻击 | 循环中普通攻击的伤害，作为本关伤害基准与 UI 参考值 | 10 |
| 意图循环 | 固定顺序循环，不随机；每项含名称、伤害、特殊标记 | 轻攻 10 → 蓄力 0 → 重击 18 |
| 特殊机制 | 无 / 蓄力 / 清 buff / 破防 / 压制资源 | 蓄力 |
| 战前提示 | 进入战斗前显示的战术提示 | 它会先蓄力再重击 |
| 战败提示 | 失败界面给出的应对建议 | 单格挡挡不住重击，试试牵制 |
| 奖励 | 经验 / 解锁卡牌 / 装备；区分首次与重复 | 首次 100 经验 + 解锁强化入口 |
| 背景 | 一句话设定 | 场馆的执法裁判机 |
| 敌人形象 | 外观描述或资源名 | 立柱式机械裁判，电子记分屏 |

**意图循环为固定顺序，不随机。** 玩家可以在一场战斗中学会节奏，第二场凭记忆提前一回合准备。这是当前数值下唯一能稳定成立的信息量来源：6 张牌组让手牌几乎是确定的，变化只能由敌人提供。

**特殊机制定义**（均以当前规则为基准实现）：

| 机制 | 规则 | 惩罚的打法 |
| --- | --- | --- |
| 无 | 只按循环出招 | — |
| 蓄力 | 循环中有一拍 0 伤害，下一拍为高伤害，意图提前显示 | 无脑对攻 |
| 破防 | 该次攻击无视格挡 | 每回合只格挡 |
| 清 buff | 清除玩家当前的战术增幅 | 先战术增幅再行动 |
| 压制资源 | 降低玩家下一回合的体力恢复（如 20 → 10） | 攒体力打大回合 |

样本使用前三类中的蓄力、破防、压制资源；清 buff 作为后续敌人候选，本版不启用。

## 4. 数值基准

| 类型 | 建议生命 | 目标回合数 | 意图伤害带 | 说明 |
| --- | --- | --- | --- | --- |
| 教学 | 30–40 | 2 | 4–6 | 两回合结束，演示开局爆发窗口 |
| 普通 | 50–60 | 5–6 | 6–10 | 大部分回合可以边打边防守 |
| 精英 | 65–75 | 6 | 8–14（含穿甲） | 要求满血进入，否则容错极低 |
| BOSS | 75–85 | 7–8 | 轻攻 10 / 重击 18 | 有明确的节奏与答题时刻 |
| 支线 | 60–70 | 5 | 6–12（含资源压制） | 可重复挑战，机制向 |

以上开局 100 体力、玩家 30 血、6 张牌组条件下的基准模拟（贪心策略，仅作方向参考）：

| 关卡 | 敌人生命 | 满血胜率 | 平均回合 | 中途受伤后胜率 |
| --- | --- | --- | --- | --- |
| 教学 6 攻 | 36 | 100% | 2.0 | — |
| 普通 10/8/8 | 55 | 100% | 5.4 | 18 血时 98% |
| 精英 8/破防 14/8 | 70 | 93% | 6.1 | 24 血时 57% |
| BOSS 10/蓄力/18 | 75 | 97% | 7.5 | 24 血时 44% |
| 支线 12/6/6 + 压制 | 65 | 100% | 5.1 | 18 血时 74% |

精英与 BOSS 的胜率对「进入战斗时的生命」非常敏感，这是关卡链需要恢复手段的直接证据（见第 6 节）。

## 5. 五个样本

### 5.1 L-1 发球机·初号（教学）

| 字段 | 内容 |
| --- | --- |
| 关卡 ID | `CH0-01` |
| 类型 | 主线（教学） |
| 敌人生命 | 36 |
| 基础攻击 | 6 |
| 意图循环 | 送球 6 → 送球 6 → 送球 6（固定） |
| 特殊机制 | 无 |
| 战前提示 | 无，由脚本引导代替 |
| 战败提示 | 不会战败；生命归零时直接重开本关并回满 |
| 奖励 | 经验 10（仅首次），无卡牌 |
| 背景 | 训练中心的发球机被改成了对战模式 |
| 敌人形象 | 立柱式发球机，机械臂夹着一支训练拍 |

引导内容按顺序触发：移动与靠近 → 按 `E` 开始 → 出牌消耗体力 → 敌人意图的含义 → 结束回合与弃手抽 5 → 第二回合提示「开局体力是满的，之后每回合只回 20」。

设计意图：36 血配合开局爆发，稳定两回合结束，玩家只需做出一次出牌决策；同时一定能看到一次敌方攻击，理解「意图 → 结算」的顺序。

### 5.2 L-2 裁判机器人（章节 0 BOSS）

| 字段 | 内容 |
| --- | --- |
| 关卡 ID | `CH0-B01` |
| 类型 | BOSS |
| 敌人生命 | 75 |
| 基础攻击 | 10 |
| 意图循环 | 判定·警告 10 → 蓄力 0（显示「下一击 18」）→ 判定·罚分 18 |
| 特殊机制 | 蓄力 |
| 战前提示 | 「它会先蓄力再重击。看到蓄力，就要决定这回合是抢输出还是先垫格挡。」 |
| 战败提示 | 「重击 18 点，一张格挡挡不住。试试用牵制把它减半，或者在蓄力回合把伤害打出去。」 |
| 奖励 | 首次 100 经验（直接升级），并解锁强化（MP）系统入口 |
| 背景 | 场馆的执法裁判机，接管了训练场的最后一关 |
| 敌人形象 | 悬浮式机械裁判，胸腔是一块不断翻牌的电子记分屏 |

设计意图：蓄力是本关唯一的新机制。三拍循环里，「蓄力」那一拍是免费输出窗口，「重击」那一拍是必须回答的问题。全速进攻的玩家四回合能打掉 75 血，但会在第 3 回合先被 10 + 18 打死——这个刀口是刻意留的。

强化（MP）解锁位按 D-024 暂缓实现，本关先保留解锁入口的位置与提示文案。

| 特殊机制 | 破防 |

### 5.5 L-5 节奏控制器（支线）

| 字段 | 内容 |
| --- | --- |
| 关卡 ID | `CH1-S01` |
| 类型 | 支线 |
| 敌人生命 | 65 |
| 基础攻击 | 12 |
| 意图循环 | 重切 12 → 搓短 6 → 拖慢 6（下回合体力恢复 -10） |
| 特殊机制 | 压制资源 |
| 战前提示 | 「它会拖慢你的恢复节奏，别指望攒够一回合的体力。」 |
| 战败提示 | 「恢复被压到 10 点的回合，只出得起一张副攻或一张格挡。」 |
| 奖励 | 首次 40 经验 + 两个急救贴；重复挑战每次 10 经验 |
| 背景 | 球馆角落里的老式节奏机，没人愿意跟它打满 |

设计意图：唯一会改变「每回合 20 点」这条规则的关卡，用来验证按关卡覆写恢复量的实现方式，同时给支线一个独立的可重复挑战价值。它也是卡组切换的第二验证点：三套牌组在此关只能感受到名称差异，正好暴露 D-024 待定的问题。

## 6. 关卡外部规则（候选，待确认）

以下四条不属于单关，但 5 个样本跑起来必须依赖它们：

1. **战败处理**：玩家生命归零后恢复至 10 点，退回训练中心，不损失已获得的东西，可重新挑战。教学关例外，直接重开并回满。
2. **关卡间恢复**：每场胜利恢复 6 点生命（相当于一次能量饮料），不超过上限。这是生命跨战斗保留、且关内禁止治疗的前提下的最低恢复量。
3. **战前使用消耗品**：战前提示界面允许打开背包治疗，进入战斗后禁止，沿用现有规则。
4. **奖励重复规则**：首次通关发放完整奖励；重复挑战只发经验，解锁类奖励不重复发放。

第 2 条若改为「回到训练中心才能恢复」，则关卡之间需要额外的移动成本；若改为「完全不恢复」，当前 30 点生命只够支撑 2 场连续战斗。

## 8. 待确认

- 第 6 节的四条关卡外部规则（战败、胜利恢复、战前补给、奖励重复）。
- 蓄力、破防、压制资源三种机制是否进入实现，优先级如何。
- 强化（MP）与卡牌解锁、装备获取三个奖励系统当前都只有占位，没有实现。
- 关卡数值为原型调参值，需试玩校准；特别是 BOSS 75 血在当前玩家 30 血下，容错窗口只有一个回合。

已在 `prototype/main.gd` 接入五个数据驱动样本，并由牌战 NPC 打开挑战选择面板。玩家可查看关卡敌人生命、固定意图循环和战前提示，在开战前切换三套主题牌组。当前 NPC 默认选中教学关 `CH0-01`；可在列表中选择其他样本。

| 设计项 | 原型状态 | 实现范围 |
| --- | --- | --- |
| 五个样本关卡 | 已实现 | 关卡 ID、名称、类型、敌人生命、意图、经验奖励和提示按配置加载 |
| 蓄力 | 已实现 | 蓄力回合伤害为 0，并显示下一击 18 点预告 |
| 破防 | 已实现 | 该次攻击无视并不消耗格挡；玩家可用牵制削弱攻击 |
| 压制资源 | 已实现 | “拖慢”意图结算后，下个玩家回合恢复 10 点体力 |
| 首次/重复奖励 | 部分实现 | 按关卡在当前运行会话记录首次领取；节奏控制器首通给 40 经验和两个急救贴，重复给 10 经验；其他关卡重复经验沿用现有牌战默认值 |
| 战败建议 | 已实现 | 失败反馈使用当前关卡配置的战败提示 |
| 战败回退与恢复 | 未实现 | 第 6 节候选规则没有落地 |
| 战前治疗 | 未实现 | 选择面板暂不开放背包补给 |
| 卡牌/装备/MP奖励 | 未实现 | 只保留现有经验与支线急救贴奖励；解锁和强化系统不在本次范围 |

首通记录、经验、等级、天赋与库存均未写入存档，重启原型会重新开始；本次实现没有新增旧数据迁移或兼容逻辑。

自动化验证覆盖关卡选择、敌人生命和意图、蓄力、破防、压制恢复、战败提示及支线首通/重复奖励：`prototype/tests/smoke_battle.gd`。其余系统回归测试见 [HANDOFF_CONTEXT.md](HANDOFF_CONTEXT.md) 的运行状态。
